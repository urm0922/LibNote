## LibNoteとは

LibNoteは、複雑な図書館業務に関するFAQ・対応ノウハウを一元管理し、どんな人でも、必要な情報にすばやくアクセスできるようにする業務支援アプリです。図書館に限らず、拠点を複数持つ現場スタッフの業務知識を標準化するアプリとして活用できます。


## 制作背景

きっかけは私の業務経験です。
いくつもの分館(拠点)を持つ大規模図書館では、正規職員・委託スタッフ・新人スタッフなど業務経験やITリテラシーが多様な人員体制で均一のサービス品質を求められます。しかしながら実際の現場では、重要な業務情報がスタッフ間で十分に共有されていなかったり、担当者や拠点によって利用者対応にばらつきが生じたりする場面がありました。
また、従来の紙やPDF中心のマニュアルは、年々文量が肥大化し、必要な情報を探しづらくうまく活用されていないという課題がありました。

LibNoteは、こうした現場課題のもとに、業務ナレッジを一元的にわかりやすく整理・共有することを目的として開発中のアプリです。


## 問題点
- 中央館と分館との情報格差があり、業務の情報が適切に共有されていない
- 紙やPDFの業務マニュアルは、業務の複雑化に伴って文量が増え、必要な情報が探しにくくなりがちである。表現が堅く、経験の浅いスタッフには理解しづらい場面がある
- 業務上の不明点は結果的に中央館に問い合わせることになり、同じ質問のやりとりが組織全体の業務量を増加させる
- 図書館は基本的に土日祝日問わずサービス提供をしているので研修の機会が少ない

### 解決案

- 業務ナレッジを一元管理し、全拠点から同じ情報にアクセスできるようにする
- カテゴリ・検索・FAQ化により必要な情報を見つけやすくする
- スタッフの問い合わせからFAQやナレッジ記事を作成し、再利用する
- 問い合わせからAIがナレッジとFAQの下書きを作成。内容確認の上、公開することで、負担を減らして正しい情報を共有できる
- ナレッジ記事やFAQにより自己学習しやすくする


## 想定ユーザー
分館(拠点)を複数持つ大規模図書館(サービス提供施設)のスタッフを想定しています。
|ロール|具体例|役割|
|:---|:---|:---|
|委託スタッフ|分館スタッフ・窓口職員・新人スタッフ|業務上の不明点を調べたい|
|直営スタッフ|中央館スタッフ・業務担当者・承認者|業務担当として業務上の不明点を回答|
|管理者|システム担当・承認者|カテゴリ管理・記事承認・ユーザー管理・AI下書き確認|


## 主な利用シーン

- 業務中にわからないことがあり、過去のナレッジやFAQを調べたいとき
- 調べても解決できず、詳しいスタッフへ問い合わせたいとき
- 問い合わせに回答や補足を追加したいとき
- 回答内容を、他のスタッフも利用できるナレッジとして残したいとき
- 新人スタッフが過去の対応を見ながら業務を学びたいとき



## 利用方法



### 1. ユーザー登録・ログイン

初めて利用する場合はユーザー登録を行います。登録済みの場合は、メールアドレスとパスワードでログインします。



### 2. ナレッジやFAQを検索

ナレッジ一覧やFAQ一覧から、知りたい内容を検索します。ナレッジはキーワードやカテゴリで絞り込むことができます。



### 3. 問い合わせを投稿

必要な情報が見つからない場合は、問い合わせを作成します。タイトル、カテゴリ、本文を入力し、必要であれば画像も添付します。作成途中の内容は下書きとして保存できます。



### 4. 担当者が回答

担当者は問い合わせの詳細画面からコメントを投稿します。回答や補足を追加し、対応が終わったら「回答済み」にします。



### 5. ナレッジとして公開

管理者が問い合わせを承認すると、AIがナレッジとFAQの下書きを作成します。管理者が内容を確認・編集したあとに公開します。



## 機能一覧

- ユーザー登録、ログイン、ログアウト
- ユーザーの権限管理
- 問い合わせの投稿、閲覧、編集、削除
- 問い合わせの下書き保存
- 問い合わせへの画像添付
- コメントによる回答、補足
- 問い合わせのステータス管理
- キーワード、カテゴリ、ステータス検索
- AIによるナレッジ・FAQの下書き作成
- ナレッジの編集、公開、下書きへの変更
- 公開済みナレッジ・FAQの閲覧
- カテゴリ管理
- ユーザー管理

※AIが作成した下書きは自動では公開されず、管理者が確認してから公開するという流れです
